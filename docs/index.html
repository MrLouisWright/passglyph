passglyph

Hieroglyphs instead of password dots. Matching passwords show matching glyphs, without the password ever being shown.

$npm i passglyph

Live demo

Type a password, then type it again. Matching passwords show the same glyphs; a typo changes them from the first wrong character on.

Type at least 8 characters in both fields.

Mode

Unsafe: the same password with each character mapped to a fixed glyph (a substitution cipher). This is what passglyph does not do:

passglyph hashes the whole prefix with a secret per-page key instead, so aaaa shows four unrelated glyphs and nothing repeats.

Alphabet32 hieroglyphs
A typo slips past one position1 in 32
…past every later position (10 chars)1 in 1015
Leak to a screenshot (no key)0 bits
If the key were stolen too5 bits per position

With 5 bits a single mistyped position is caught 31 times out of 32, and the following positions almost always differ as well. The glyphs reveal nothing without the per-page key, which is non-extractable and never leaves memory.

How it works

  • No per-character mappingGlyph i is HMAC-SHA-256(key, password[0..i]) truncated to 4–6 bits (default 5), so repeated characters get unrelated glyphs.
  • Per-page random keyA 128-bit key imported as a non-extractable WebCrypto key. Without it a screenshot or recording reveals nothing.
  • The real input stays a password fieldGlyphs are drawn on an aria-hidden canvas overlay. Autofill, password managers and screen readers work as usual.
  • No code points in the DOMGlyphs come from a bundled sprite drawn with Path2D, so a DOM snapshot is identical for any two passwords.
  • Accessible and CSP-safeA polite live region announces whether passwords match. No style injection, no eval, no network, no storage.
  • Graceful fallbackFalls back to normal dots if canvas, Path2D or WebCrypto is missing.

Quick usage

Vanilla

import { attach } from 'passglyph';

const detach = attach(
  document.querySelector('#password'),
  document.querySelector('#confirm'),
  { onChange: (match) => submit.disabled = match === false },   // mode: 'inline' by default
);
// later: detach();

Web component

<script type="module">import 'passglyph/element';</script>

<pass-glyph mode="inline" bits="5">
  <input type="password" autocomplete="new-password">
  <input type="password" autocomplete="new-password">
</pass-glyph>

Every option is documented in the passglyph docs.
